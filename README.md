# E-Commerce Performance & Inventory Dashboard

A comprehensive **E-Commerce Performance & Inventory Dashboard** built using **Microsoft Power BI** to analyze e-commerce sales performance, customer behavior, product performance, and inventory health.

The dashboard provides an interactive and user-friendly interface that enables users to explore key e-commerce KPIs and analyze sales and inventory performance across different dimensions such as **product, category, brand, customer segment, country, order status, payment method, shipping mode, and inventory status**.

---

## Dashboard Overview

The E-Commerce Performance & Inventory Dashboard consists of three main sections:

- **Overview**
- **Sales Analysis**
- **Inventory Analysis**

Users can interact with different filters and slicers to dynamically analyze e-commerce data and gain meaningful business insights.
