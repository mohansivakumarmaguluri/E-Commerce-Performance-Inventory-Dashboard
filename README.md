# 🛒 E-Commerce Performance & Inventory Dashboard

An interactive **E-Commerce Performance & Inventory Dashboard** built using **Microsoft Power BI** to analyze sales performance, customer behavior, product performance, and inventory health.

This project follows an end-to-end data analytics workflow, from **raw data cleaning and preprocessing using Python** to **data modeling and interactive visualization in Power BI**.

---

## 📊 Dashboard Overview

The dashboard consists of three main analytical sections:

### 🏠 1. Overview

Provides a high-level view of overall e-commerce business performance.

Key areas include:

- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Customer Performance
- Product Performance
- Sales Trends
- Inventory Overview
- Overall Business KPIs

### 💰 2. Sales Analysis

Provides detailed insights into sales performance and revenue generation.

Key analysis includes:

- Sales trends over time
- Revenue performance
- Product and category analysis
- Customer segment analysis
- Order status analysis
- Payment method analysis
- Discount analysis
- Sales performance by region
- Top-performing products
- Order and quantity trends

### 📦 3. Inventory Analysis

Provides insights into product stock levels and inventory health.

Key analysis includes:

- Total stock quantity
- Inventory status
- Reorder-level analysis
- Product stock availability
- Warehouse distribution
- Low-stock products
- Stock performance by category
- Inventory distribution across products
- Products requiring replenishment
